3. Разрешения устройства

  • Микрофон — упражнения на говорение, звонки с AI-тьютором, вопросы Луне голосом и, если пользователь включил эту функцию, распознавание имени «Луна», пока Приложение открыто.
  • Распознавание речи — системная служба Apple или Google для голосовых команд Луне; обработка регулируется политиками этих компаний.
  • Face ID / Touch ID — по желанию, для быстрого входа. Биометрические данные обрабатывает только система устройства; Приложение получает лишь результат проверки.
  • Фото — только снимки, выбранные пользователем для обращения.
  • Камера — не используется. Библиотека голосовой связи содержит поддержку видео, которую Приложение не включает.

Каждое разрешение запрашивается системой устройства и может быть отозвано в ее настройках.

4. Цели обработки

Предоставление доступа к Приложению и обучению; работа AI-тьютора, помощника Луны и автоматической проверки заданий; учет прогресса, токенов и призов; организация занятий с преподавателями; рассмотрение обращений; безопасность и предотвращение злоупотреблений; исполнение требований закона.

5. Функции искусственного интеллекта и согласие

AI-тьютор, Луна и автоматическая проверка работают с помощью внешних AI-сервисов. Перед первой передачей голоса или текста Приложение показывает окно с описанием передаваемых данных и получателей и запрашивает согласие. Согласие можно отозвать в любой момент: Профиль → Настройки → «Обработка данных ИИ». Без согласия функции AI недоступны, остальное Приложение работает. Ответы AI создаются автоматически и могут содержать неточности.
